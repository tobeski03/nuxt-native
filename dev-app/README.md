# Nuxt-native Dev App

The Dev App is the companion app for wireless Nuxt-native development.

1. Install the APK on the Android phone.
2. Run `npx nuxt-native dev . --qr` in a Nuxt-native project.
3. Open Nuxt-native Dev and scan the QR code from inside the app.

The app connects to the temporary local development server and reloads native route assets as files change.
